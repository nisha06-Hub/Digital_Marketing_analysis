# Digital Marketing Analysis

## Project Overview

This project analyzes digital marketing campaign performance to understand how different platforms and campaigns contribute to leads, sales, revenue, and overall return on investment. The analysis helps identify high-performing campaigns and provides insights to support better marketing decisions.

---

## Business Objective

The objective of this project is to analyze marketing campaign data and answer important business questions such as:

* Which platform generates the highest revenue?
* Which campaigns generate the most leads?
* Which platform provides the best Return on Investment (ROI)?
* How effectively are leads converted into sales?
* How can marketing performance be improved?

---

## Dataset Description

The dataset contains information about digital marketing campaigns, including:

| Column          | Description                          |
| --------------- | ------------------------------------ |
| Date            | Date of the campaign activity        |
| Platform        | Digital marketing platform           |
| Campaign Name   | Name of the marketing campaign       |
| Ad Spend        | Amount spent on advertisements       |
| Leads Generated | Number of leads generated            |
| Sales Converted | Number of leads converted into sales |
| Revenue         | Total revenue generated              |

## Key Performance Indicators (KPIs)

The following KPIs were used to measure marketing performance:

* **Total Ad Spend**
* **Total Leads Generated**
* **Total Sales Converted**
* **Total Revenue**
* **Return on Investment (ROI)**
* **Conversion Rate**

### KPI Formulas

**ROI (%)**

`((Revenue - Ad Spend) / Ad Spend) × 100`

**Conversion Rate (%)**

`(Sales Converted / Leads Generated) × 100`

## SQL Analysis

SQL queries were used to analyze the marketing data and answer questions such as:

* Total revenue generated by each platform
* Total ad spend by each platform
* Campaigns with the highest revenue
* Platforms with the highest number of leads
* Average revenue generated by campaigns

---

## Key Insights

The analysis provides insights into:

* The best-performing marketing platforms based on revenue.
* Campaigns that generate the highest number of leads.
* The relationship between advertising spend and revenue.
* Platforms with better lead-to-sales conversion performance.
* Opportunities to improve marketing budget allocation.

---

## Business Recommendations

Based on the analysis, the following recommendations can help improve marketing performance:

* Allocate more budget to high-performing platforms and campaigns.
* Optimize campaigns with high ad spend but low revenue.
* Focus on improving lead conversion for campaigns generating many leads but fewer sales.
* Regularly monitor ROI and conversion rates to make data-driven marketing decisions.
* Identify successful campaign strategies and apply them to underperforming campaigns.
