# Digital Marketing Analysis

## Project Overview

This project analyzes digital marketing campaign performance to understand how different platforms and campaigns contribute to leads, sales, revenue, and overall return on investment. The analysis helps identify high-performing campaigns and provides insights to support better marketing decisions.

---

## Business Objective

The objective of this project is to evaluate the performance of digital advertising campaigns and identify:

* Which platform generates the highest revenue?
* Which campaigns generate the most leads?
* Which platform provides the best Return on Investment (ROI)?
* How effectively are leads converted into sales?
* How can marketing performance be improved?

## Tools Used

* **Microsoft Excel** – Data cleaning, analysis, Pivot Tables, and dashboard creation
* **MySQL** – Data querying and analysis
* **GitHub** – Project documentation and version control

## Key Performance Indicators

The dashboard tracks the following KPIs:

- Total Revenue
- Total Advertising Spend
- Total Leads Generated
- Total Sales Converted
- Return on Investment (ROI)
- Conversion Rate

### KPI Formulas

**ROI (%)**

`((Revenue - Ad Spend) / Ad Spend) × 100`

**Conversion Rate (%)**

`(Sales Converted / Leads Generated) × 100`

## Dashboard

The Digital Advertising Performance Dashboard provides an overview of campaign performance across different advertising platforms.

The dashboard includes:

- Revenue by Platform
- Ad Spend vs Revenue by Platform
- Leads and Sales Generated by Platform
- Conversion Rate by Platform
- ROI by Platform
- ROI Status Distribution


## Key Insights

- Google Ads generated the highest number of leads.
- Facebook achieved the highest conversion efficiency, with a conversion rate of approximately 30.23%.
- Instagram delivered the highest ROI among the analyzed platforms.
- Most campaigns achieved a positive ROI, accounting for approximately 94% of the total campaigns.
- Revenue exceeded advertising spend across most platforms, indicating overall positive campaign performance.
